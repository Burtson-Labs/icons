# AGENTS.md

Instructions for AI coding agents working in this repository. People should start with [README.md](README.md).

This is `@burtson-labs/icons`: an open-source 24px stroke icon set, published to npm and served from [icons.burtson.ai](https://icons.burtson.ai), which doubles as the CDN. If you are using the icons in another app rather than changing this repo, read [icons.burtson.ai/agents](https://icons.burtson.ai/agents/) or the skill in [`skills/burtson-icons/SKILL.md`](skills/burtson-icons/SKILL.md) instead.

## Layout

| Path                            | What                                                                                  |
| ------------------------------- | ------------------------------------------------------------------------------------- |
| `icons/<name>.svg`              | Icon source, one per icon                                                             |
| `icons/<name>.json`             | `tags`, `categories` (first is primary), `aliases`, `contributors`                    |
| `categories.json`               | Categories and their descriptions                                                     |
| `brands/`, `scripts/brands.mjs` | Third-party logos (separate entry, trademarks of their owners; see TRADEMARKS.md)     |
| `scripts/`                      | Validator, icon lint, originality check, build, scaffolder, status                    |
| `dist/`                         | Built package (generated, not committed)                                              |
| `preview/`                      | README sheets and accent icons (generated by the build, committed)                    |
| `site/build.mjs`                | Gallery for icons.burtson.ai, written to `site/dist/` and synced by the hosting repo  |
| `site/agents.mjs`               | `llms.txt`, `llms-full.txt` and the `/agents/` page, generated from the icon metadata |
| `skills/burtson-icons/SKILL.md` | The Agent Skill for people using the set (`npx skills add burtson-labs/icons`)        |
| `design/DESIGN.md`              | The drawing spec. Read it before drawing or changing an icon                          |
| `test/`                         | `node --test` suites, including snapshots                                             |

## Commands

```bash
npm ci
npm run new -- <name>   # blank icon + metadata, pre-filled from design/backlog.json
npm run check           # validate, icon lint, originality, build, lint, format, typecheck, site, tests
npm run icons:lint:fix  # rewrite icon source formatting
npm run site            # build site/dist (needs npm run build first)
```

`npm run check` must pass before a change is done. If `typecheck` cannot resolve `@burtson-labs/icons`, run `node scripts/link-self.mjs` (a stale self-link in `node_modules`).

## Rules

- Follow [design/DESIGN.md](design/DESIGN.md): 24×24 grid, 2px round stroke on the root only, no fills or transforms, geometry inside the 1px margin, at most 8 elements.
- Every drawing is original. Never trace or copy paths from Lucide, Feather, Tabler, Heroicons, Material or any other set; `npm run originality` fails near-copies.
- Names are kebab-case, noun first, modifier last. Give each icon at least three search tags, and put other sets' names in `aliases`.
- No private product or client names anywhere in the repo. It is public.
- The package has zero runtime dependencies; keep it that way. React and MUI stay optional peers.
- Copy in the README and site is plain and factual.
- Do not bump the version or edit `CHANGELOG.md` unless asked; releases are cut by the maintainer.
